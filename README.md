# Network Security and Cryptography Algorithms

A collection of Python implementations of fundamental Network Security and Cryptography algorithms.
## Algorithms
- Caesar Cipher
- Playfair Cipher
- Hill Cipher
- Rail Fence Cipher
- Euclidean Algorithm
- Extended Euclidean Algorithm
- DES
- AES
- RC4
- RSA
- Diffie-Hellman Key Exchange
- Euler's Totient Function
- Chinese Remainder Theorem
- Fermat's Little Theorem

## Requirements
- Python 3.x
- PyCryptodome: used for DES, AES, RC4 library-based implementations.
- PyCipher: Used for classical cipher implementations such as Caesar, Playfair, Rail Fence, and Hill Cipher.

```bash
pip install pycryptodome 
pip install pycipher
